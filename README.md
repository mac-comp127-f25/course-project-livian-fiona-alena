Feeding Frenzy
Team members: Livian, Alena, Fiona

Project description:

It is a fish survival game, where Player controls "playerFish" by mouse or keyboard to avoid larger predator, and eat smaller npc Fish. For running code, java 17+ is required as Kilt Gragh library is nedded, and main class is FeedingFrenzy

Most of artworks (fish image and background) are exported from publicly available website. Background image: "seabedBg"; Fish image: "clown fish.png", "bluefish.png", "tuna.png", "shark.png"(https://pixie.haus/gallery?filter=collections);
The logic of game is inspired by a Chinese game, english version is like Feeding Frenzy.
Collision logic inspired from course exercise Cell Absorption.(overlap, collide)
Instructor and preceptor helped a lot on code formatting, adjustment, Hitbox idea, collision and so on, giving useful and inspiring advices.

There are some known issues in current version, but these can be addressed with more time. For example sound is not included, and some fish have different resolution which can lead to mismatch between visual size and collisio hitbox, so we add a topbar which show what fish player can eat.

This project is a simple, casual game designed for entertainment and learning purpose. Because of its straightforward mechanics, the game is accessible to non-technical users, so anyone can run it and immediately understand how to play. It also does not collect or handle sensitive data or cause direct ham. However, this game heavily rely on visual cues, including fish size and movement. This might limit accessibility for player with low vision, blindness or color blindness
